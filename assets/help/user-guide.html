Cargo Track 使用帮助

所有台账数据保存在本机。选择一条货物记录后，底部显示可用操作。按 F1 随时打开帮助。

货物与状态 · 删除与恢复 · Fleet · Voyages · 筛选与导出 · 备份与恢复 · 设置

首次使用

  1. Fleet → Add vessel 添加船舶；On Shore 是内置岸上地点。
  2. New voyage 建立航程，+ Add vessel 添加停靠点并选择 Current stop。
  3. + Add cargo 录入货物描述、From、To，可补充实物编号和备注。也可不建航程直接录入岸上转运。

货物、状态与详情

NO 是转运段编号，Cargo ID 是同一件货物的固定身份。Details 展示当前确认位置、转运链和审计记录；已交付货物可添加下一转运段，保留 Cargo ID。

选中货物，用底部状态下拉直接选择 Waiting（待收货）、On Board（在本船）、Done（已交付），无需确认弹窗。选中状态即表示该状态属实，保存后更新位置和完成日期。Done 的日期按业务时区记录；回退为未完成会清空本段完成日期。快速收货/交付按钮仍可使用。旧段已有后续转运时不能直接改状态，先处理后续段。

Edit fields 修改描述、备注等；More → Correct record 用于路线或状态更正，可填写详细原因。状态下拉自动记录前后状态和修改来源。保存失败会提示原因，不把未保存的状态当成成功。

删除记录与误删恢复

选中记录 → 底部 Delete → 核对编号和描述、填写删除原因 → 确定。Waiting 与最后一个 Done 段可删除；On Board 先改为符合实际情况的 Waiting 或 Done。有后续段时先处理后续段。

删除后记录从正常列表移除，原数据和审计保留。筛选范围选择 Deleted records，选中记录点击 Restore 可恢复。已有替代转运或前段未完成时，系统会阻止恢复并说明原因。

Fleet 船队

Add vessel 添加，Rename 改名，Deactivate 停用，Reactivate 重新启用。Delete 将船舶从正常选择列表移除，历史转运仍保留船名。当前航程停靠点或未完成转运引用此船时，先移除相关停靠点、处理货物，再删除。同名船可重新添加为新身份。

Voyages 航程与停靠点

New empty voyage 建立空航程；Copy selected route 复制路线。建立新航程后旧航程成为只读历史。Delete 移除航程；删除当前航程会清空当前站，但货物不删除。

停靠点按钮选择当前站；右侧箭头菜单可 Move earlier/later 或 Remove。重复到访同一条船是独立停靠点。Previous / Next / Choose 用于切换当前站；本船清单不依赖当前航程。

视图、筛选、搜索与导出

All transfers 查看台账；Current stop 查看当前站相关任务；On my vessel 查看本船货物。搜索支持 NO、Cargo ID、描述、实物编号和备注。状态、船舶和范围筛选可组合；Clear filters 清除条件。摘要数量使用完整数据，表格结果数使用当前筛选。

范围包含 Open only、Include completed、Completed only、Deleted records。Export 导出完整筛选结果到 CSV 或 Excel，并非仅导出当前页。首版不支持 Excel 导入。

备份、恢复与故障

Backup → Create backup 创建经校验的副本；Open backup folder 打开默认备份目录。Restore backup 先预检文件，再确认替换。恢复前自动保存现有数据库的安全副本。

恢复期间暂时禁止写入。替换失败会尝试回滚；如果回滚也失败，程序保持维护模式，并提供保留文件路径。不要把残留临时文件当作成功备份。先保留原文件和安全副本，再按错误信息恢复。

设置、目录、字体与主题

Business time zone 使用 Windows 时区显示名称，保存后影响未来业务日期，历史完成日期不重算。Transfer vessel name 可设置本船显示名。

Database folder / Backup folder → Choose 选择可写目录。切换数据库目录会安全复制当前台账并切换，原文件保留；不覆盖已有数据库。载入另一份数据库应使用 Backup → Restore。程序记住路径，重新启动继续使用。

Appearance 选择 Light 或 Dark；Font size 选择 10 / 11 / 12 pt，默认 11 pt。点击 Save 后立即生效并记住设置。Inter 字体随包提供，无需安装。设置更改后需核对所选数据库路径。

键盘与大屏缩放

F1 帮助；Ctrl+F 搜索；Ctrl+N 新增货物；Enter 打开所选货物详情；Esc 关闭弹窗；Tab 在控件间移动。表格可横向滚动并拖动表头改变列宽。窗口支持高 DPI；文字偏小时在 Settings 选择 Large。
