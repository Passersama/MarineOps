# Cargo Track Logo V1

使用内置 imagegen 工具生成，透明背景 PNG。设计结合货箱、追踪航线与当前站点，采用项目 UI 的海军蓝 #173A63 和紫色 #6F4CC3。字标为 Cargo Track。

## 生成提示词

Use case: logo-brand
Asset type: finished logo for Cargo Track, a Windows desktop application for tracking cargo transfers between fleet vessels.
Primary request: Design one distinctive, polished, minimal logo combining a compact cargo box silhouette with a continuous route forming a subtle letter C and one terminal tracking dot. The route should feel like deliberate maritime movement, not a generic location pin. Keep the symbol beautifully simple, legible at small sizes, with balanced geometry and restrained corner rounding.
Style/medium: flat, crisp vector-like graphic, production identity design.
Composition: one horizontal logo lockup centered in a wide canvas, symbol on the left and exact wordmark on the right, ample transparent margins; symbol visually around the wordmark cap-height to 1.5 times cap-height. No extra panels or variant grid.
Color palette: navy #173A63 for main symbol and wordmark; a single restrained purple #6F4CC3 tracking dot accent, echoing the application's current-stop color.
Typography: exact text "Cargo Track", expertly kerned contemporary humanist sans-serif, medium to semibold, readable and calm. Spell C-a-r-g-o space T-r-a-c-k exactly.
Background: truly transparent alpha.
Constraints: one clean flat logo; no slogan, extra text, mockup, ship illustration, glossy effects, gradients, shadows, decorative ocean waves, hairline details, watermark or presentation-board labels. The symbol must be recognizable and reproducible in a single color.
